# 집 PC 외부 원격 제어 안내 (그대로 따라 하기)

밖(휴대폰·노트북)에서 집 PC를 그대로 조작하는 설정입니다.
집 PC의 Claude(자비스)·Canva·파일을 외부에서 화면 그대로 씁니다.

권장 도구: **Chrome 원격 데스크톱** (무료, 설치 쉬움, 휴대폰 지원, 구글 계정만 필요)

---

## 준비물
- 집 PC: 항상 켜두고 인터넷 연결. Chrome 브라우저 설치.
- 밖에서 쓸 기기: 휴대폰 또는 노트북.
- 구글 계정 1개(집 PC와 외부 기기가 **같은 계정**이어야 함).

---

## A. 집 PC에서 (한 번만)

### 1단계. Chrome 설치·로그인
1. `google.com/chrome` 접속 → Chrome 내려받아 설치.
2. Chrome 우측 상단 사람 아이콘 → 구글 계정으로 로그인.

### 2단계. 원격 데스크톱 설정
1. Chrome 주소창에 입력: `remotedesktop.google.com/access`
2. **"이 기기 설정"** 아래 내려받기(파란 원 아이콘) 클릭 → 설치.
3. 컴퓨터 이름 정하기(예: `집컴`) → 다음.
4. **PIN 6자리 이상** 입력(외부 접속 시 매번 이 번호로 잠금 해제). 기억할 것.
5. "온라인" 표시가 뜨면 완료.

### 3단계. 절전 방지 (중요)
집 PC가 잠들면 접속이 끊깁니다.
1. `윈도우키 + I` → 시스템 → 전원.
2. "화면 끄기" "절전" 모두 **"안 함"** 으로 설정.
   (노트북이면 "전원 연결 시" 기준으로.)

---

## B. 밖에서 쓸 기기에서

### 휴대폰
1. 앱스토어/플레이스토어에서 **"Chrome 원격 데스크톱"** 설치.
2. 앱 실행 → 집 PC와 **같은 구글 계정**으로 로그인.
3. 목록에서 `집컴` 선택 → PIN 입력 → 집 화면 그대로 조작.

### 노트북·다른 PC
1. Chrome에서 `remotedesktop.google.com/access` 접속(같은 계정 로그인).
2. `집컴` 클릭 → PIN 입력 → 접속.

---

## C. 접속 후 자비스 쓰기
원격으로 집 화면에 들어간 뒤에는 집에서와 똑같습니다.
- Claude Code 실행 → 새 대화창 → 평소처럼 지시.
- Canva·Google Drive·파일 모두 집 PC 그대로 사용.

---

## 보안 수칙
- PIN은 남과 공유 금지. 유추 쉬운 숫자(생일·1234) 피하기.
- 구글 계정에 **2단계 인증** 켜기: `myaccount.google.com/security`.
- 공용 PC에서 접속했다면 사용 후 반드시 로그아웃.

---

## 대안 도구 (참고)
| 도구 | 특징 | 비고 |
|------|------|------|
| Chrome 원격 데스크톱 | 무료·가장 쉬움 | **권장** |
| AnyDesk / TeamViewer | 개인 무료·성능 좋음 | 별도 계정, 상업용 유료 |
| Windows 원격 데스크톱(RDP) | OS 기본 내장 | Pro 버전 필요·설정 어려움·비권장 |

설정 중 화면을 캡처해 다음 대화창에 올리시면, 그 지점부터 다시 안내하겠습니다.
