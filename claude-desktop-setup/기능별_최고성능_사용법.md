# Claude 기능별 최고 성능 사용법 (교수님 업무 기준)

## A. 핵심 원칙 3가지
1. 모델은 항상 최상위(Opus). `/model`로 설정.
2. 작업 1건 = 대화창 1개. 주제 섞이면 품질·맥락이 흐려짐.
3. 자료는 파일로 첨부. 추측 대신 원본을 읽고 작업하게 함.

## B. 업무별 최적 사용법

### 1) 논문·학술글
- 시작 시: 주제·학술지·인용양식·마감을 한 번에 제시.
- 자료: 참고문헌 PDF를 첨부하면 직접 읽고 인용.
- 검증: "내용·형식 검증 강하게" → reviewer 2인 교차검증.
- 산출: .docx.

### 2) PPT·강연자료 (디자인 포함)
- **Canva 연동**이 핵심. 연동하면 슬라이드를 실제로 디자인·생성·내보내기.
- 시작 시: 청중·발표시간·핵심 메시지·브랜드 톤 제시.
- 산출: Canva 디자인 + .pptx 내보내기. 발표자 노트 자동 포함.

### 3) 책 집필
- 분량·톤·목차를 먼저 합의.
- 장(章) 단위로 진행해 맥락 유지.
- 구어체/문어체 자동 구분.

### 4) 연구자료 정리·리서치
- 깊은 조사는 "deep research" 요청 → 다중 출처 검색·교차검증·인용 보고서.
- 산출: 출처·날짜·핵심요약 3열 표. 불명확 출처 ⚠️.

### 5) 앱 기획·구현
- 요구사항 → 화면 흐름 → (원하면) 실제 코드·테스트까지.
- GitHub 연동 시 코드 저장·버전관리 자동.

## C. 외부 연동으로 성능 확장 (사람이 1회 로그인)

| 연동 | 무엇이 가능해지나 | 교수님 업무 활용 |
|------|-------------------|------------------|
| Canva | 디자인·PPT 자동 생성·편집·내보내기 | 강의자료, 포스터, 카드뉴스 |
| Google Drive | 드라이브 문서 읽기·작성 | 자료 수집, 협업 문서 |
| GitHub | 코드·문서 버전관리 | 앱 개발, 원고 백업 |

연동 방법: Claude Code 대화창에서 해당 서비스 연결 요청 → 뜨는 화면에서 1회 로그인.

## D. 편의 기능
- 슬래시 명령: `/help` 전체 보기, `/model` 모델 변경, `/fast` 빠른 모드.
- 반복 작업 자동화: "매번 ~할 때 ~해줘" 요청 시 자동 규칙(훅) 설정 가능.
- 파일 첨부: 대화창에 PDF·이미지·문서를 끌어다 놓으면 바로 읽음.

## E. 하면 안 되는 것 (품질 저하)
- 한 대화창에서 여러 주제 동시 진행 → 맥락 오염.
- 자료 없이 "알아서 써줘" → 추측·환각 위험. 항상 원본 제공.
- 하위 모델 사용 → 학술·검증 작업 품질 저하.
